Privacy policy

Application: SkyTower RFI archive
Updated: 8 November 2026

Data accessed and purpose

The workflow accesses the Google Drive files and folders needed to maintain the configured RFI archive. This includes file contents, file and folder names and identifiers, timestamps, sizes, checksums, archive manifests, operational evidence, and the Excel register. Authorization or account verification may also return basic account information identifying the authorized Google account.

These data are used to save correspondence and attachments, detect changes, reconcile archive coverage, update the register, and recover interrupted operations. The requested Drive scope permits access to existing archive files; the scheduled workflow is configured to operate within the designated archive folder.

Storage and processing

Archive files, the register, and operational evidence are retained in the owner's configured Google Drive folder. Processing takes place in the GitHub Actions job workspace. Temporary job files are removed when the workspace is discarded. Operational logs can contain counts and error categories and are retained according to the repository's GitHub settings.

OAuth credentials are stored as encrypted GitHub Actions secrets and supplied to the workflow at runtime. Google and GitHub process data as necessary to provide their respective storage, authorization, and execution services.

Use and sharing

The application does not sell Google user data, use it for advertising, or publish the private archive. The scheduled workflow does not send archive materials to language models for processing or training. Access to the archive and workflow is controlled through the owner's Google Drive and GitHub permissions.

SkyTower RFI archive's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Retention, revocation and deletion

The owner controls retention of archived files and operational evidence in Google Drive and can delete them using Drive. The owner can revoke the application's access in Google Account connections and remove the workflow's GitHub secrets. Revoking access prevents future authorized access; it does not delete existing archived files.

Contact and changes

For privacy questions or deletion assistance, contact the application owner using the support email shown on the Google authorization screen. Changes to this policy will be published on this page with an updated date.
