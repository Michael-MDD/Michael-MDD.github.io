SkyTower RFI archive

SkyTower RFI archive is a private automation workflow for maintaining a construction Request for Information (RFI) archive. It reads authorized correspondence and attachments from Aconex and stores archive copies and an Excel register in the owner's designated Google Drive folder.

Google Drive access

The owner authorizes Google Drive access using a desktop OAuth client and rclone. The workflow reads archive files and metadata, uploads new correspondence, and updates the register and operational records. It requests the Drive scope because it must work with the owner's existing archive.

Who uses the application

This application is intended for its owner and explicitly authorized operators. Scheduled jobs run on GitHub Actions using the owner's configured credentials.
